# 匯入大會系統瀏覽器擴充功能

最後整理：2026-11-09

## 目前進度與目的

本文件記錄本次需求討論的共識，供後續接續實作。**目前只完成需求討論與唯讀調查，尚未開發擴充功能，也未操作正式報名。** 使用者本次要求先保存決策，回家後再繼續。

將 `ictc-2027-registration` 已登記的資料，透過瀏覽器擴充功能帶入大會系統，減少服事者逐人勾選的工作。

- 目標網址與活動識別碼：不記錄於公開文件；實作時由管理員在本機提供，勿提交至版本控制。
- 目標活動：2027 國際華語相調特會。
- 使用者：具有相關系統操作權限的管理員／服事者弟兄；不假設使用者懂程式。
- 第一版僅處理本活動的 2/20、2/21 參加狀態。

### 人工確認必須在勾選之前

最初討論為「自動填表後人工送出」，但使用者提供的畫面標示「在格子打勾，就是替這位報名」，使用者也確認沒有看到儲存按鈕。

因此已共同決定：**將勾選視為可能立即寫入的報名操作，先預覽、人工確認，最後才實際勾選或取消勾選。** 不得先改動網站，再等待一個可能不存在的送出按鈕。

目前尚未以登入後的網路請求驗證實際儲存機制，也未驗證如何判斷儲存成功。

## 預定操作流程

1. 管理員下載最新 CSV，並親自登入目標活動頁面。
2. 開啟擴充功能、載入 CSV，檢查兩天的活動欄位對應。
3. 挑選本次處理的人員，配對目標網站會員；有疑義的資料列為待處理。
4. 預覽每人的日期、網站原值、預計新值與兒童人工確認提醒。
5. 管理員按「確認套用」後，才執行已確認的勾選與取消勾選。
6. 管理員確認網站結果，完成必要的兒童分類設定，再回原後台手動更新匯入狀態。

## 資料與欄位對應

### 兩天的參加狀態

專案初始活動定義如下；這是程式庫中的定義，尚未核對線上目前名稱。

| 來源活動名稱 | 目標欄位 |
| --- | --- |
| 華語特會（第一天） | 2/20（六） |
| 華語特會（第二天，含擘餅） | 2/21（日） |

| CSV 值 | 處理方式 |
| --- | --- |
| 參加 | 預計勾選；原本已勾選則無須改動。 |
| 不參加 | 預計取消勾選；原本未勾選則無須改動。 |
| 未回覆 | 保留網站原值。 |

來源也有青年大會、午餐與晚餐等活動，**不得只依日期挑選 CSV 欄位**。

CSV 以當前活動標題作為欄名，而標題可修改且資料庫未限制標題唯一。實作時應顯示欄位對應；缺少必要欄位、重複欄名或無法確認對應時停止套用，不自行猜測。這是調查後整理的實作防護方向，具體介面尚未製作。

### 兒童

目標網站有兒童分類欄位；具體資格與收費規則以管理員登入後的活動說明為準，不在公開文件轉載。

現有來源的「兒童」標記不能完整判斷這些條件。第一版只提醒，分類由管理員確認與設定；兒童仍以個別報名者處理，不合併到家長。

## 已完成的唯讀調查

### 現有專案

- 後台「統計與匯出」已有「下載報名登記 CSV」，檔名為 `registration-export.csv`，使用 UTF-8 BOM。
- CSV 包含流水號、姓名、區、兒童、家長姓名、匯入狀態，以及各公開活動的參加狀態等欄位。
- 匯出涵蓋全體有效登記，排除取消／作廢資料，不套用畫面目前的區或兒童篩選。因此擴充功能仍需提供人員選取。
- CSV 具有公式注入防護；解析時須留意資料可能有保護用的前置單引號，不可任意刪除正常姓名字元。
- 本系統以區與正規化姓名限制有效登記唯一；不同區仍可同名。來源唯一不代表目標網站也唯一。
- 現有匯入狀態包含 `pending`、`imported`、`reimport_needed`，可由後台手動更新。
- 現有報名資料沒有電話、Email、身分證等資料；如果目標流程要求額外資訊，不得自行補造。

## 接續實作前需驗證的事項

以下是尚未完成的技術驗證，不代表已取得正式環境寫入或測試報名的授權。

- 確認登入後的 DOM、姓名與區排的取得方式、勾選元件及欄位定位。
- 確認搜尋、篩選、分頁或虛擬捲動是否影響名單完整性；不可把未載入的人員判為不存在。
- 確認兩個系統的區名是否一致；目標截圖部分人員區排為「兒童」，不可直接假定來源區可一律比對。

- 確認兒童日期勾選是否觸發監護人、資格等額外流程；若出現，需停下交由管理員處理。
- 定義執行中發生錯誤、頁面變動或部分完成時的停止與結果呈現方式，避免重複或錯誤操作。
- 使用去識別化測試資料驗證 CSV 解析、欄位對應、同名處理、差異預覽與不修改未選取人員的行為。
